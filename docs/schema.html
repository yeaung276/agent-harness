API tokens

api_tokens

ColumnTypeNotes
iduuidPrimary key, gen_random_uuid().
user_iduuidReferences users.id: who created it, shown as Created by. Deleted with that user.
nametextThe label the user gave it.
token_hashtextUnique. SHA-256 of the token, hex. The token itself is never stored.
token_starttextThe first 8 characters, pat_ and 4 more, so the user can tell tokens apart.
expires_attimestamptz30 days, 90 days or 1 year after creation. Null means it never expires.
last_used_attimestamptzNull until first used. Updated at most once a minute.
created_attimestamptznow().

Every user sees every token and can revoke any of them. Revoking deletes the row.

Workspaces

workspaces

ColumnTypeNotes
iduuidPrimary key, gen_random_uuid().
nametextUnique. 1–63 lowercase letters, digits and -, not starting or ending with -.
statustextWhether its web server is running or stopped. Starts as stopped.
user_iduuidReferences users.id: who created it, shown as Created by. A user who created a workspace can't be deleted.
created_attimestamptznow().
updated_attimestamptznow(). Set again by each zip upload.

Only the app limits status to running and stopped; the database takes any text, so a new status needs no migration.

A workspace's files live in <WORKSPACES_DIR>/<id>, created empty with the row and deleted with it. A delete moves the directory to <WORKSPACES_DIR>/.deleted and removes it in the background. An uploaded zip waits in <WORKSPACES_DIR>/.uploads until it is extracted or refused. Anything left in either folder is removed when the app next starts. WORKSPACES_DIR defaults to /workspaces. The path is not stored.

Every user sees every workspace and can delete any of them.
