API tokens

api_tokens

ColumnTypeNotes

user_iduuidReferences users.id: who created it, shown as Created by. Deleted with that user.
nametextThe label the user gave it.
token_hashtextUnique. SHA-256 of the token, hex. The token itself is never stored.

expires_attimestamptz30 days, 90 days or 1 year after creation. Null means it never expires.

Every user sees every token and can revoke any of them. Revoking deletes the row.

Workspaces

workspaces

ColumnTypeNotes
iduuidPrimary key, gen_random_uuid().
nametextUnique. 1–63 lowercase letters, digits and -, not starting or ending with -.
statustextWhether its web server is running or stopped. Starts as stopped.
launch_optionsjsonbThe last launch: command, port, network and the env it ran with, PORT and the workspace's env merged in, its values encrypted. A request to a stopped web server starts it again from this, exactly as launched. Null until the first launch; cleared by stop.
user_iduuidReferences users.id: who created it, shown as Created by. A user who created a workspace can't be deleted.
created_attimestamptznow().
updated_attimestamptznow(). Set again by each zip upload.

Only the app limits status to running and stopped; the database takes any text, so a new status needs no migration.

A workspace's files live in <WORKSPACES_DIR>/<id>, created empty with the row and deleted with it. A delete moves the directory to <WORKSPACES_DIR>/.deleted and removes it in the background. An uploaded zip waits in <WORKSPACES_DIR>/.uploads until it is extracted or refused. Anything left in either folder is removed when the app next starts. WORKSPACES_DIR defaults to /workspaces. The path is not stored.

Every user sees every workspace and can delete any of them.

Sandbox activity

sandbox_activities

ColumnTypeNotes
iduuidPrimary key, gen_random_uuid().
workspace_iduuidReferences workspaces.id. Deleted with the workspace.
kindtextlaunch or exec. A relaunch woken by a request is another launch.
commandtextThe command as given.
statustextrunning until it settles. An exec: succeeded on exit code 0, failed on any other or on timeout. A launch: succeeded once it answers on its port, failed if it exits, times out or finds no free pool port first.
exit_codeintegerNull while running, for a timed-out exec, and for a launch that succeeded.
outputtextstdout and stderr together, the last 16 KB: an exec's whole run, a launch's log up to the moment it settled. Empty while running.
created_attimestamptznow(). Indexed with workspace_id for the newest-first list.
finished_attimestamptzWhen it settled. Null while running.

The worker running the sandbox writes each row; the web app reads them for a workspace's Sandbox activity tab, 20 to a page. Like status on workspaces, kind and status are limited only by the app.

Browsers

browser_sessions

ColumnTypeNotes
iduuidPrimary key, gen_random_uuid(). The session id in the API.
workspace_iduuidReferences workspaces.id: the workspace whose background process the tab can reach. Null for a session that reaches only public sites. Deleted with the workspace.
recordbooleanWhether the tab is filmed and allows screenshots. Only with a workspace. Default false.
statustextalive while its tab is open, closed once it is closed: by the API, after 5 minutes unused, when the worker shuts down, or when a call finds its tab gone. A closed session answers 404.
urltextWhere the tab is, saved after each call. Null on a blank tab.
storage_statejsonbThe tab's cookies and local storage, saved after each call.
user_iduuidReferences users.id: who created it, shown as Created by. A user who created a session can't be deleted.
last_used_attimestamptznow(). Set again by each call and by closing.
created_attimestamptznow().

The worker running the browser writes each row. Rows are never deleted; closing sets status. Like status on workspaces, status is limited only by the app.
