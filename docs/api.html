API

The public API other systems call, at /api/v1.

Authentication

Every call sends Authorization: Bearer <token>. Any user creates tokens on the API tokens page of the web app, and a call made with one acts as the user who created it. The token is shown once, when it is created; only its SHA-256 hash is stored, in api_tokens.

A token is pat_ followed by 32 random bytes, base64url: 47 characters in all. Every user sees every token and can revoke any of them; a revoked token stops working on the next call.

Workspaces

A workspace is a named, empty directory that files are uploaded to and a web server runs from. The table is workspaces.

Every route here also answers 401 as described in Authentication.

The workspace object

Endpoints

POST/api/v1/workspacesCreate a workspace and its empty directory

Body

{
  "type": "object",
  "required": [
    "name"
  ],
  "properties": {
    "name": {
      "pattern": "^[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?$",
      "type": "string"
    }
  }
}

Response 201

The workspace object, with status stopped.

Errors · 400

The name doesn't match the pattern. Fastify's validation body: statusCode, code, error, message.

Errors · 409

A workspace already has this name.

DELETE/api/v1/workspaces/:idDelete a workspace and its directory

Params

{
  "type": "object",
  "required": [
    "id"
  ],
  "properties": {
    "id": {
      "format": "uuid",
      "type": "string"
    }
  }
}

Response 204

No body. The workspace and its directory are gone at once; the files in it are removed afterwards, so the call doesn't wait on them. If the directory can't be moved aside, nothing is deleted.

Errors · 404

No workspace has this id.

POST/api/v1/workspaces/:id/uploadUpload a zip and extract it into the workspace

Params

{
  "type": "object",
  "required": [
    "id"
  ],
  "properties": {
    "id": {
      "format": "uuid",
      "type": "string"
    }
  }
}

Body

multipart/form-data, for example curl -F file=@site.zip -F path=site.

FieldRequiredNotes
fileYesThe zip. At most 100 MB uploaded and 1 GB once extracted.
pathNoThe folder inside the workspace to extract into, like site or site/assets. Created if missing. Defaults to the workspace root.

A file in the zip replaces a file at the same path; other files already there stay.

Response 202

The files are extracted in the background. The body is the folder they go into, relative to the root ("" for the root), and the number of files in the zip.

{
  "type": "object",
  "required": [
    "path",
    "files"
  ],
  "properties": {
    "path": {
      "type": "string"
    },
    "files": {
      "type": "integer"
    }
  }
}

Errors · 400

The workspace is left as it was when:

  • file is missing or isn't a zip.
  • path leads outside the workspace, for example with ...
  • An entry in the zip leads outside the folder, or is a link.
  • The body isn't multipart/form-data.

Errors · 404

No workspace has this id.

Errors · 413

The upload is over 100 MB, or the zip would extract to over 1 GB. Nothing is extracted.
