TypeScript SDK

The official TypeScript client for Code-Harness. Create sandboxes and browsers, run commands, read and write files, launch apps and drive a browser against them, from your code or from a LangChain agent.

Installation

npm install @code-harness/sdk

The SDK runs on Node.js 20+ and Bun. To use a sandbox as a deepagents backend or to add the LangChain middleware, also install the peer dependencies:

npm install deepagents langchain @langchain/core zod

Without them, import from @code-harness/sdk/client: the same Client, Sandbox and Browser, in ESM and CommonJS, with no deepagents, LangChain or zod. Its Sandbox has no deepagents file methods; it reads, edits and lists files with readFile, editFile and tree.

Quickstart

Create an API token on the API tokens page of the web app, then:

import { Client } from "@code-harness/sdk"

const client = new Client({
  baseUrl: "https://harness.example.com",
  token: process.env.CODE_HARNESS_TOKEN,
})

const sandbox = await client.createSandbox({ name: "hello" })

await sandbox.write("/workspace/index.js", `require("http").createServer((_, res) => res.end("hi")).listen(process.env.PORT)`)
const { url } = await sandbox.launch({ command: "node index.js", port: 3000 })
console.log(url)

const page = await sandbox.browser.navigate("/")
console.log(page.text) // "hi"

await sandbox.close()

Client

The entry point. One client holds the server URL and token and creates every Sandbox and Browser.

client.getSandbox()

client.createBrowser()

createBrowser(): Promise<Browser>

A free Browser on the public internet, not tied to any sandbox. To open an app running in a sandbox, use sandbox.browser instead.

const browser = await client.createBrowser()
const page = await browser.navigate("https://example.com")
await browser.close()

client.getBrowser()

getBrowser(id: string): Browser

A handle to an existing free browser, without a request. The next call on it throws NOT_FOUND when no browser has this id.

Sandbox

An isolated Linux environment with its own files, where you run commands and one long-running app. Files live under /workspace and commands run from there. A sandbox is kept, with its files, until it is deleted.

Sandbox extends deepagents' BaseSandbox, so it can be passed as an agent's backend as is. See Integrations.

Properties

PropertyTypeDescription
idstringThe sandbox's id.
namestringThe sandbox's name.
envKeysstring[]The names in its env, sorted.
createdAtDateWhen it was created.

sandbox.execute()

execute(command: string): Promise<ExecuteResponse>

Runs command with sh -c from /workspace and waits for it to end. Returns { output, exitCode, truncated }: output is stdout and stderr together, the last 16 KB of it. A command that fails still resolves; check exitCode. A command still running after the sandbox's timeoutMs is killed, and resolves with exitCode: null and output ending in timed out after <ms> ms.

const { output, exitCode } = await sandbox.execute("npm ci && npm test")

Dependency folders like node_modules may be empty on the next command. Install in the same command that needs them.

Files

Paths are absolute under /workspace, or relative to it. A path outside /workspace fails with invalid_path.

MethodDescription
read(path, offset?, limit?)A text file's lines, numbered, from line offset.
write(path, content)Writes a file, with its folders, overwriting it.
edit(path, oldString, newString, replaceAll?)Replaces oldString, which must occur once unless replaceAll.
delete(path)Deletes a file or folder.
ls(path)A folder's entries, with sizes.
glob(pattern, path?)Files matching a glob, like **/*.ts.
grep(pattern, path?, glob?)Lines matching a literal string, with file and line number.
uploadFiles(files)Writes [path, bytes][], overwriting. Text only; other content fails with invalid_path.
downloadFiles(paths)Reads files as bytes.

These follow the deepagents backend protocol: they don't throw for a missing or bad path, they return { error }. uploadFiles and downloadFiles return one result per path, so some can succeed while others fail. Folders like node_modules and .git can't be read or written this way; use execute.

const [result] = await sandbox.downloadFiles(["/workspace/package.json"])
if (result.error) throw new Error(result.error)
const pkg = JSON.parse(new TextDecoder().decode(result.content!))

sandbox.uploadAsZip()

uploadAsZip(zip: Blob | Uint8Array | ArrayBuffer, options?: { path?: string }): Promise<{ path: string; files: number }>

Uploads a zip and extracts it into the folder at path, under /workspace or relative to it, created if missing. Defaults to /workspace. A file in the zip replaces a file at the same path; other files stay. Use it to load a project or folder into the sandbox in one call.

Resolves once the zip is checked, with the folder and how many files it has; the files appear in the sandbox shortly after. At most 100 MB uploaded and 1 GB extracted, otherwise throws TOO_LARGE and nothing is extracted. Throws INVALID_REQUEST when it isn't a zip, path is outside /workspace, or an entry leads outside the folder.

import { readFile } from "node:fs/promises"

await sandbox.uploadAsZip(await readFile("site.zip"), { path: "site" })

sandbox.launch()

launch(options: LaunchOptions): Promise<{ url: string }>
OptionTypeDescription
commandstringStarts the app, like npm ci && npm start.
portnumberThe port the app listens on. PORT is set to it.
envRecord<string, string>Added to the sandbox's env for this app.
network{ allow?: string[]; deny?: string[] }Hosts the app and commands can reach. See Network.

Starts the app in the background and resolves once it listens on port, up to 90 seconds, with its public URL. One app runs per sandbox. An app with no traffic for 15 minutes is stopped, and the next request to its URL starts it again.

Throws CONFLICT when an app is already running; call stop() first. Throws UPSTREAM_FAILED when the app exits or never listens; the message ends with the last lines of its log.

sandbox.logs()

logs(options?: { tail?: number }): Promise<string[]>

The last tail lines the app wrote, 200 by default, 1,000 at most. After the app ends, the last line says how.

sandbox.stop()

stop(): Promise<void>

Stops the app. Files are kept. Resolves also when nothing is running.

sandbox.browser

readonly browser: Browser

The sandbox's own Browser. It runs next to the sandbox and can open its app: a URL that is a path, like /login, opens the app. Reading the property sends no request; the first call on it creates the browser, and every later call uses the same one. With the sandbox's record, it records a video into the sandbox each time it closes. Its screenshots are also saved into the sandbox.

await sandbox.launch({ command: "npm ci && npm start", port: 3000 })
const page = await sandbox.browser.navigate("/")

sandbox.close()

close(): Promise<void>

Closes sandbox.browser, stops the app and deletes the sandbox with its files. This can't be undone. Any later call throws NOT_FOUND.

Browser

A browser tab kept between calls: cookies, storage and URL last across calls. The page is read as text plus numbered refs, and you click and type by ref. A browser with no call for 5 minutes is closed, and its next call opens it again at the same URL with the same cookies.

Properties

PropertyTypeDescription
idstring | nullThe browser's id. null on sandbox.browser until its first call.
sandboxIdstring | nullThe sandbox it belongs to, or null for a free browser.
recordbooleanWhether it records.

Page

read, click and type resolve with the page:

interface Page {
  title: string
  url: string
  text: string
  refs: { ref: number; tag: string; role: string | null; name: string; value: string; placeholder: string; href: string }[]
}

Each takes a waitFor, and navigate an until: { selector?, text?, timeoutMs? }. The call waits until an element matching selector is visible and text is on the page, up to timeoutMs (10 seconds by default, 60 at most), then acts. When the wait runs out it throws TIMEOUT without acting.

browser.navigate()

navigate(url: string, options?: { until?: WaitFor }): Promise<Page & { status: number | null; error: string | null }>

Goes to url and resolves once the page loads. A page that fails to load still resolves; check error. until running out also resolves, with error: "waitFor timed out".

browser.read()

read(options?: { maxChars?: number; waitFor?: WaitFor }): Promise<Page>

browser.click()

click(ref: number, options?: { waitFor?: WaitFor }): Promise<Page>

browser.type()

type(ref: number, text: string, options?: { submit?: boolean; waitFor?: WaitFor }): Promise<Page>

Types into the field. submit presses Enter after.

let page = await browser.navigate("/login")
const email = page.refs.find(r => r.name === "Email")!
page = await browser.type(email.ref, "ada@example.com", { submit: true, waitFor: { text: "Welcome" } })

browser.screenshot()

screenshot(options?: { fullPage?: boolean; waitFor?: WaitFor }): Promise<{ png: Uint8Array; path: string | null }>

Takes a PNG and resolves with its bytes. On sandbox.browser, it is also saved into the sandbox and path is where, which sandbox.downloadFiles reads; on a free browser, path is null.

browser.run()

run(code: string, options?: { timeoutMs?: number }): Promise<{ result: unknown; error: string | null; durationMs: number }>

Runs Playwright code against the page, with page in scope. timeoutMs defaults to 60 seconds, 120 at most.

browser.close()

close(): Promise<void>

Closes the tab, and saves the video of a recording browser. A later call opens it again.

Errors

Every method throws CodeHarnessError, except the deepagents file methods, which return { error }. deepagents' SandboxError.isInstance() recognises it.

import { CodeHarnessError } from "@code-harness/sdk"

try {
  await sandbox.launch({ command: "npm start", port: 3000 })
} catch (err) {
  if (err instanceof CodeHarnessError && err.code === "CONFLICT") {
    await sandbox.stop()
  } else throw err
}
PropertyTypeDescription
codestringOne of the codes below.
statusnumber | nullThe HTTP status, or null when no response came.
messagestringThe server's message.
CodeStatusWhen
INVALID_REQUEST400An option is out of range or malformed.
AUTHENTICATION_FAILED401No token, or it is unknown, revoked or expired.
NOT_FOUND404The sandbox or browser doesn't exist.
CONFLICT409The name is taken, or an app is already running.
TOO_LARGE413A zip is over 100 MB, or extracts to over 1 GB.
RATE_LIMITED429The sandbox already has 5 open browsers, counting those of other clients on the same sandbox.
UPSTREAM_FAILED502The app didn't start.
TIMEOUT504A browser call or its wait ran out.
NETWORK_ERRORnoneThe server couldn't be reached.
UNKNOWNany otherThe server answered with a status not listed here, like 500.
