Commands

Commands run from a shell where the server runs: a checkout with its .env, or docker compose exec app. They read the same config as the server and talk to Postgres directly.

Authentication

There is no register page. A user exists only after user:create adds them, and logs in on the web with that email and password. Passwords can't be changed for now.

user:create

bun run user:create <email>
StepWhat happens
EmailTrimmed and lowercased. Not an email address → exit 1.
PasswordAsked twice, without echo. From a pipe, the first line of stdin, asked once. Fewer than 8 characters, or the two don't match → exit 1.
SaveHashed with argon2id and inserted into users. The email is already there → exit 1, nothing changes.
DonePrints the new user's id → exit 0.

Database

Migrations are SQL files in drizzle/, committed with the code. bun run db:generate writes a new one from the changes in src/db/schema.ts. The server never migrates; run db:migrate by hand before starting a version with new migrations.

db:migrate

bun run db:migrate
StepWhat happens
ReadThe migrations in drizzle/, and the last one applied, from drizzle.__drizzle_migrations.
ApplyEvery newer one, in order, in one transaction, each recorded in drizzle.__drizzle_migrations. One fails → all roll back, exit 1.
DoneExit 0. Nothing newer → nothing changes.
