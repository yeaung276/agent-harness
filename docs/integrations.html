Integrations

Give an agent framework a Code-Harness sandbox to write code in, run it, launch the app and check it in a browser. Each integration is part of @code-harness/sdk.

LangChain

A Sandbox is a deepagents sandbox backend, like @langchain/daytona and @langchain/modal. Passed as backend, it is where deepagents' file tools and execute act. Three LangChain middlewares add the rest:

MiddlewareTakesAdds
createCodeHarnessMiddlewarea sandboxLaunching the app and checking it in the sandbox's browser.
createBrowserUseMiddlewarea browserThe browser tools alone.
createSkillUseMiddlewarea sandbox and skill pathsAgent skills stored and run in the sandbox.

Installation

npm install @code-harness/sdk deepagents langchain @langchain/core zod

Set CODE_HARNESS_BASE_URL and CODE_HARNESS_TOKEN, or pass them to Client.

deepagents tools

With the sandbox as backend, the agent gets deepagents' own tools on it:

ToolDoes
ls, read_file, write_file, edit_file, glob, grepWork on the sandbox's files, under /workspace.
executeRuns a shell command from /workspace, as sandbox.execute().

createCodeHarnessMiddleware()

createCodeHarnessMiddleware(options: { sandbox: Sandbox }): AgentMiddleware

The tools to launch the sandbox's app and check it in sandbox.browser: launch_app and app_logs, and every browser use tool on sandbox.browser, where a path like / opens the launched app. It also adds a note to the system prompt: files are in /workspace, dependencies are installed in the command that needs them, and the app is opened in the browser at a path like /.

ToolArgumentsDoes
launch_appcommand, port, env?Stops the running app, starts this one, and returns its URL once it listens on port.
app_logstail?The last lines the app wrote.
 
import { createDeepAgent } from "deepagents"
import { ChatAnthropic } from "@langchain/anthropic"
import { Client, createCodeHarnessMiddleware } from "@code-harness/sdk"

const client = new Client()
const sandbox = await client.createSandbox({ name: "todo-app", record: true })

try {
  const agent = createDeepAgent({
    model: new ChatAnthropic({ model: "claude-sonnet-5-5" }),
    backend: sandbox,
    middleware: [createCodeHarnessMiddleware({ sandbox })],
  })

  const result = await agent.invoke({
    messages: [{ role: "user", content: "Build a todo app with Express and check it works in the browser" }],
  })
  console.log(result.messages.at(-1)?.content)
} finally {
  await sandbox.close()
}

createBrowserUseMiddleware()

createBrowserUseMiddleware(options: { browser: Browser }): AgentMiddleware

The browser tools, on any Browser: a free one from client.createBrowser() to browse the public internet, or sandbox.browser. It needs no backend, so it also works with createAgent. Don't add it next to createCodeHarnessMiddleware, which already has these tools.

ToolArgumentsDoes
browser_navigateurl, until?Opens a URL and returns the page as text and numbered refs.
browser_readmaxChars?, waitFor?The current page as text and numbered refs.
browser_clickref, waitFor?Clicks a ref and returns the page after.
browser_typeref, text, submit?, waitFor?Types into a ref and returns the page after.
browser_screenshotfullPage?, waitFor?Takes a PNG. On sandbox.browser, saves it in the sandbox and returns its path, which read_file opens; on a free browser, returns the image.
 
import { createAgent } from "langchain"
import { Client, createBrowserUseMiddleware } from "@code-harness/sdk"

const browser = await new Client().createBrowser()

const agent = createAgent({
  model: "anthropic:claude-sonnet-5-5",
  middleware: [createBrowserUseMiddleware({ browser })],
})

await agent.invoke({ messages: [{ role: "user", content: "What is the top story on news.ycombinator.com?" }] })

createSkillUseMiddleware()

createSkillUseMiddleware(options: { sandbox: Sandbox; sources: string[] }): AgentMiddleware

deepagents' standard skills middleware, createSkillsMiddleware, with the sandbox as the place skills are kept and run. A skill is a folder with a SKILL.md, as in deepagents. sources are folders in the sandbox: a folder of skills, like /workspace/skills/, or one skill, like /workspace/skills/pdf/. A later source wins over an earlier one for a skill with the same name.

The middleware lists each skill's name and description in the system prompt. The model opens a skill's SKILL.md with read_file and runs its scripts with execute, both in the sandbox, so the agent's backend must be the same sandbox.

Put skills into the sandbox with sandbox.uploadAsZip(), or with any file method.

import { readFile } from "node:fs/promises"
import { createDeepAgent } from "deepagents"
import { Client, createSkillUseMiddleware } from "@code-harness/sdk"

const sandbox = await new Client().createSandbox({ name: "reports" })
await sandbox.uploadAsZip(await readFile("skills.zip"), { path: "/workspace/skills" })

const agent = createDeepAgent({
  model: "anthropic:claude-sonnet-5-5",
  backend: sandbox,
  middleware: [createSkillUseMiddleware({ sandbox, sources: ["/workspace/skills/"] })],
})

Lifecycle

WhatLives
Sandbox, its files and skillsUntil sandbox.close(). Every run given the same sandbox shares them.
The launched appUntil the next launch_app or sandbox.stop(). With no traffic for 15 minutes it stops, and the next request to its URL starts it again.
The browserClosed when the run ends. The next run's first browser call opens it again, at the same URL with the same cookies. sandbox.browser is created on its first call.

To keep a sandbox across processes, store sandbox.id, or give it a name, and connect again with client.getSandbox(idOrName).

Errors

A tool that fails returns Error: <status or code> <message> to the model as its result, and the run goes on, so the model can fix the cause and try again. A failed launch_app returns the last lines of the app's log. Calls outside a tool, like createSandbox or sandbox.close(), throw CodeHarnessError.
